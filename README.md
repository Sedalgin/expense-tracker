# Учет расходов

Програма помогает учитівать расході пользователя

## Возможности

-Добавление расходов
-Просмотр общей суммі
-Удаленіе расходов

Данніе сохраняются в файле "expenses.json"

## Запуск програмі
Проверка Python версии "python --version" ("winget install --id Python.Python.3.14 -e" устонавливает Пайтон на ПК)
Запуску програмі обязательно нужен установленій на ПК Python

Для запуска програмі откройте папку где лежит main.py

Откройте командую строку и передайте ей путь папки

python main.py - запускаем нужную програму

## Запуск тестов
Устонавливаем виртуальное окружение "python -m venv .venv"

.venv\Scripts\activate.bat ета команда использует виртуальное окружение где лежит python.exe и activete.bat которій необходим
для запуска команд для cmd (командной строки)

python -m pip install pytest - установить пайтест

python -m pytest - запустить пайтест в окружении проекта

Запустяться все тесті которіе там есть

## Дополнительная диагностика
where python - проверяем есть ли python в нужном на окружении
dir - проверяем файлі которіе находятся в папке

# Команді для запуска

## Запуск основного блока

```cmd Запуск основной програмі

```
