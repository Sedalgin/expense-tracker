# Импорт и `if __name__ == "__main__"`

## Что происходит при `import`
`from practice_oop import Expense` → Python **выполняет весь файл** сверху вниз:
1. создаёт классы и функции;
2. выполняет **любой код на верхнем уровне** (вне функций и классов);
3. блок `if __name__ == "__main__":` — **пропускает**.

## Что такое `__name__`
Встроенная переменная каждого файла.

| Как файл запущен | `__name__` равно |
|---|---|
| `python expense.py` (запустили сам файл) | `"__main__"` |
| `import expense` (импортировали) | `"expense"` |

Поэтому блок `if __name__ == "__main__":` работает **только при прямом запуске**.

## Пример
```python
class Expense:
    ...

first = Expense("Еда", -1)      # ⚠️ выполнится и при запуске, и при ИМПОРТЕ

if __name__ == "__main__":
    print(first)                # только при python этот_файл.py
```

## Почему это важно
- Код вне `if __name__` срабатывает при **каждом** импорте, в том числе из тестов.
- Из-за `Expense("Еда", -1)` на верхнем уровне pytest не смог даже загрузить тесты.
- Поэтому класс живёт в **чистом** файле (`expense.py`), без тренировочного кода.

## Импорт ≠ вызов
- **Импорт** — принести класс в файл: `from expense import Expense`.
- **Вызов** — использовать метод, со скобками: `expense.change_amount(200)`.
- Удалили метод → ломается **вызов** (`AttributeError`), а не импорт.

## ❓ Вопрос с собеседования
**Зачем писать `if __name__ == "__main__":`?**
<details><summary>Ответ</summary>
